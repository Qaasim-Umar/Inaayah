# Project Instructions

## Writing and copy

- Never use em dashes or en dashes in user facing website copy or project documentation.
- Use commas, colons, full stops, or words such as "to" instead.
- Rewrite optional hyphenated wording when a clear alternative is available.
- Hyphens remain allowed where they are required by code syntax, framework utilities, file names, URLs, and package names.
